# Lesson 1

## 1. Set up once

1. Clone this project, or download and **extract** the ZIP.
2. [Create your own empty GitHub repository](https://github.com/new) — no README, license, or .gitignore.
3. In the project folder, run setup:

| Computer | Setup |
| --- | --- |
| Windows | Double-click **setup.cmd** |
| macOS / Debian | Open Terminal here: `bash setup.sh` |

4. Paste **your new repository link** when asked.

Setup installs the tools and uploads the backend to **your repository**.

## 2. Start

Run in the project folder:

| Computer | Command |
| --- | --- |
| Windows PowerShell | `.\setup.cmd run` |
| macOS / Debian | `bash setup.sh run` |

Open **http://localhost:8080/** after you see **Started**.

Keep the terminal open. **Ctrl+C** stops the app.

## 3. Do the lesson

Follow [the checklist](LESSON1_CHECKLIST.md). Rerun setup to save and push your changes.
