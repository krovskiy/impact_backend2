# Impact backend

1. Run **setup.cmd** (Windows) or `bash setup.sh` (Mac/Linux). Paste your own [empty GitHub repository](https://github.com/new) link.
2. Prepare [PostgreSQL](database/README.md).
3. Start: `.\setup.cmd run` or `bash setup.sh run`. Open **http://localhost:8080/**.
